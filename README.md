# qa_python
Тестирование BooksCollector

В проекте реализованы автотесты для проверки класса `BooksCollector`.

Проверяемые методы:

1. Добавление книг

+ Проверка добавления новых книг
+ Проверка на недобавление книги длиной более 40 символов.

2. Работа с жанрами

+ Проверка установки жанра для книг.
+ Проверка на неустановление несуществущего жанра.
+ Проверка на получение жанра книги.
+ Проверка получения списка книг с определённым жанром.
+ Проверка получения словаря всех книг и их жанров.

3. Книги для детей

+ Проверка на добавление в список книг для детей подходящих жанров.

4. Избранное

+ Проверка добавления книги в избранное.
+ Проверка на недоваление несуществующей книги в избранное.
+ Проверка удаления книги из избранного.
+ Проверка получения списка избранных книг.
